# 🧹 HubCleaner AI 2026

O **HubCleaner AI** é uma solução automatizada em Python que conecta a API do **HubSpot**, utiliza a inteligência artificial do **Google Gemini** para detectar contatos e leads suspeitos/spam, e envia relatórios detalhados diretamente para um canal do **Discord**.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.12+**
- **HubSpot API SDK** (Gestão de contatos)
- **Google Gemini API** (Análise inteligente de dados)
- **Discord Webhooks** (Notificações em tempo real)
- **python-dotenv** (Gestão segura de variáveis de ambiente)
